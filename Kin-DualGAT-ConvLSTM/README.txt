# Kin-DualGAT-ConvLSTM
Official implementation of "A Basketball Defensive Footwork Quality Assessment Method Based on Offensive and Defensive Distance Fields and Postural Attention Mechanisms".

## Structure
- `configs/`: Hyperparameters and configuration.
- `data/`: Dataset loaders and download scripts.
- `models/`: Core network components and architecture.
- `baselines/`: Benchmark models.
- `scripts`: Train, evaluate, and validation scripts.
